Git commands used in the terminal

1. git init
   Initializes a new Git repository in the current directory.

2. git status
   Shows the repository's current state, including untracked, modified, and staged files.
   This command was run five times.

3. git add testing.py
   Stages testing.py so its changes can be included in the next commit.

4. git commit -m "file added"
   Creates a commit from staged changes with the message "file added".

5. git restore testing.py
   Discards unstaged changes to testing.py and restores the version from the index.

6. git status --short
   Shows a concise summary of modified and untracked files.

7. git --no-pager log -5 --oneline
   Shows the five most recent commits in a compact format without opening a pager.

8. git remote -v
   Shows the configured remote repositories for fetch and push.

9. git remote set-url origin https://<TOKEN>@github.com/yashmalthane22/github-workshop.git
   Updates the origin URL. The personal access token is intentionally redacted.

10. git push origin master
    Pushes the master branch to the origin remote.
